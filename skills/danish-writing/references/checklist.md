# Danish translation-tell checklist

Check a draft against each section. These are the patterns that make Danish read like it was translated from English. When something hits, rewrite the whole sentence. Don't just swap the word.

`references/examples.md` takes priority over this list if they disagree.

## 1. Compounds (særskrivning)

Danish compounds are written as one word. Splitting them is the most visible tell.

| Wrong | Right |
|-------|-------|
| software udvikler | softwareudvikler |
| kunde service | kundeservice |
| test miljø | testmiljø |
| bruger oplevelse | brugeroplevelse |
| sikkerheds opdatering | sikkerhedsopdatering |

Use a hyphen when one part is an abbreviation, a number, or a word Danes treat as foreign: *API-kald*, *PR-review*, *5-årsplan*, *Slack-kanal*.

## 2. Capitalization

- Headings use sentence case: *Vores nye strategi*, not *Vores Nye Strategi*.
- Weekdays, months, languages, nationalities, and job titles are lowercase: *mandag*, *oktober*, *dansk*, *svensk*, *direktør*, *produktejer*.
- *it* and *pc* are lowercase in Danish: *it-afdelingen*, *pc'en*.

## 3. Word order

- Main clauses put the verb second (V2): *I dag lancerer vi…*, not *I dag vi lancerer…*.
- In subordinate clauses, *ikke* and other short adverbs go before the verb: *fordi vi **ikke har** tid*, *hvis du **allerede har** gjort det*.

## 4. Punctuation and typography

- **Commas:** always put a comma after a subordinate clause that opens the sentence (*Når du er færdig, kan du…*). Don't add English-style commas after short opening adverbials (*I dag kan vi…*, not *I dag, kan vi…*). For a comma before a subordinate clause (startkomma), pick one style and use it throughout.
- **Genitive:** no apostrophe: *Peters bil*, not *Peter's bil*. Names ending in s, x, or z get a bare apostrophe: *Anders' bil*.
- **Abbreviations with endings** take an apostrophe: *PR'en*, *API'et*, *pc'en*.
- **Quotes:** pick one style and use it throughout. »…« is the classic Danish choice. Don't mix styles.
- **Numbers:** decimal comma and thousands point: *1.250,50*. Currency comes after: *1.250 kr.* Put a space before %: *25 %*.
- **Dates and times:** *2. oktober 2026* or *2.10.2026*, and *kl. 14.30*, not *14:30*, in running text.
- Don't use *pr.* and *per* interchangeably: Danish uses *pr.* (*pr. måned*).

## 5. Translated idioms and phrasings

| English-shaped | Danish |
|----------------|--------|
| i slutningen af dagen (*at the end of the day*) | når alt kommer til alt, i sidste ende |
| tage et kig på | kigge på, se på |
| adressere et problem | tage hånd om, løse, tage fat på |
| lave en forskel | gøre en forskel |
| ende op med | ende med |
| lad mig vide | sig til, giv besked |
| på ugentlig basis | hver uge, ugentligt |
| ved udgangen af dagen (*by end of day*) | i løbet af i dag, inden fyraften |
| at være i stand til at | at kunne |
| Vi er glade for at kunne annoncere… | Nu kan vi fortælle, at…, or just state the news |
| Jeg håber, denne mail finder dig vel | (drop it) |
| Det er vigtigt at bemærke, at… | (drop it, or *Bemærk, at…*) |
| det giver mening (overused) | det er logisk, det hænger sammen, det er en god idé |

## 6. False friends

| Danish word | Means | For the English meaning, use |
|-------------|-------|------------------------------|
| eventuelt | possibly | *eventually* → til sidst, med tiden |
| aktuelt | currently | *actually* → faktisk |
| realisere | carry out, make real | *realize* (become aware) → indse, gå op for |
| kontrollere | check, verify | *control* (steer) → styre |
| sensibel | sensitive | *sensible* → fornuftig |
| sympatisk | likeable | *sympathetic* → forstående, medfølende |
| supportere | cheer for (a team) | *support* → støtte, understøtte |
| levere på | (not idiomatic) | *deliver on* → indfri, leve op til |
| eje (en opgave) | own property | *own a task* → have ansvaret for, stå for |

## 7. Stiff, noun-heavy style

Danish prefers verbs and active voice.

| Stiff | Better |
|-------|--------|
| foretage en vurdering af | vurdere |
| gøre brug af | bruge |
| med henblik på at | for at |
| i tilfælde af, at | hvis |
| i forbindelse med (as a catch-all) | ved, når, til, or rewrite |
| Hvad angår X, … | Rewrite with X as subject |
| Det blev besluttet at… | Vi besluttede at… |

- The s-passive is natural for routine processes (*Filen opdateres hver nat*). The tell is a *blev*-passive that hides who did it.
- Avoid *-ende* chains copied from English *-ing*: *værende ansvarlig for*, *omhandlende*. Rewrite them as a clause.

## 8. Linking words and rhythm

- Don't start every other sentence with *Derudover*, *Desuden*, *Endvidere*, or *Yderligere*.
- *Dog,* at the start of a sentence copies *However,*. Use *Men…* or put *dog* inside the sentence: *Det virker dog ikke.*
- English builds long sentences with many clauses. Split them into shorter Danish main clauses.

## 9. Tone and format

- Understate. Cut superlatives and enthusiasm (*fantastisk*, *spændende*, *utroligt*) unless they carry information. No exclamation marks in professional text.
- Emails: *Hej [navn]* is the normal opener. Close with *Venlig hilsen*, *Mvh.*, or *Hilsen*, depending on formality. Don't use English-style openers and closers.
- Don't add headings, bold, and bullet points to short messages. Danes write short emails and Slack messages as plain prose.
- Use one form of address throughout (*du*, *I*, or *De*).

## 10. Read-aloud test

Read each sentence as if saying it to a Danish colleague. If nobody would say it that way, rewrite it.
